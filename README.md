# GenLedge homepage prototype

Local Next.js / TypeScript / Tailwind homepage based on the October 31 briefing. Pallet informs the visual direction; Nauta informs relevant industry storytelling. Content is adapted to GenLedge's capabilities.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3000. Production check: `npm run build`. Type check: `npm run typecheck`.

## Included

- Responsive homepage with mobile navigation and section anchors.
- Four-stage sales-order demonstration with play/pause, selectable steps, arrow-key navigation, and reduced-motion support.
- Wholesale distribution, manufacturing, and field services sections.
- Operator, ERP, permissions, and onboarding sections.
- Workshop and sign-in links to the existing GenLedge website. No forms submit data from this prototype.

## Review notes

All order examples and dashboard records are illustrative sample data, not a connected product. No competitor customer logos, certifications, or performance claims are used. No backend is required.

Industry photographs are downloaded from Unsplash. See `ASSETS.md` for sources. The original full-color GenLedge logo is used in the header and footer. Final imagery and copy need brand review before production. Booking links use the existing `/free-ai-workshop/` destination; no booking has been submitted.
